# Projeto: Personalização de Cartão com CSS
2
 
3
## Objetivo
4
 
5
Neste projeto, explorei como o CSS pode alterar a aparência de um cartão utilizando propriedades de estilo como largura, altura e espaçamento interno.
6
 
7
## Propriedades Testadas
8
 
9
Durante a atividade, modifiquei algumas propriedades para observar as mudanças no visual do cartão:
10
 
11
- width (largura)
12
- height (altura)
13
- padding (espaçamento interno)
14
 
15

17

## Alterações Realizadas
26
 
27
Realizei testes com diferentes valores para entender como cada propriedade influencia o layout da página.
28
 
29
### Width
30
 
31
Ao aumentar a largura, o cartão ficou mais espaçoso.
32
 
33
### Height
34
 
35
Ao modificar a altura, houve mais espaço para exibir o conteúdo.
36
 
37
### Padding
38
 
39
Ao aumentar o padding, o conteúdo ficou mais afastado das bordas, deixando o cartão mais organizado e agradável visualmente.

41
## Observações
42
 
43
As alterações permitiram compreender como o CSS controla a estrutura visual dos elementos da página. Pequenas mudanças nos valores podem gerar diferenças significativas na apresentação do conteúdo.
